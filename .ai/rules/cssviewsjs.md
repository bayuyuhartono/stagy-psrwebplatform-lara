# Cssviewsjs

## CMS brand palette is centralized
Use the CMS theme tokens defined in resources/css/theme.css: navy #0B1849, green #124D1C, gold #E4B028, and canvas #EBEDE3. Reference them through Tailwind utilities (cms-navy, cms-green, cms-gold, cms-canvas); do not repeat the hex values in templates.
